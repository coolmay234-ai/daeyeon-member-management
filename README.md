# 마음수련 대연점 회원관리

회원 등록, 주간 출석 확인, 회원별 상세 기록과 메모를 관리하는 웹앱입니다.

## 사용 방법

1. `index.html`을 더블클릭해 브라우저에서 엽니다.
2. **회원 등록**에서 이름과 과정을 입력합니다.
3. **주간현황**에서 출석과 지원 내용을 기록합니다. 위쪽 화살표로 주를 바꿀 수 있습니다.
4. **회원관리**에서 이름 검색과 과정별 조회를 합니다.
5. **상세기록**에서 평가를 선택하고, 메모는 **메모 저장**을 누릅니다.

## 저장 안내

입력한 내용은 현재 컴퓨터의 현재 브라우저 저장소(localStorage)에 저장됩니다. 서버로 전송하지 않으며, 다른 컴퓨터나 브라우저와 공유되지 않습니다. 브라우저 데이터를 지우면 기록도 삭제될 수 있습니다. 시크릿 창에서는 창을 닫으면 기록이 사라질 수 있습니다. 로컬 미리보기에서 입력한 기록은 GitHub Pages 주소로 자동 이동하지 않습니다.

## GitHub Pages에 올리기

이 폴더 안의 `index.html`, `styles.css`, `app.js`, `.nojekyll`, `README.md`, `.gitignore`를 저장소 맨 위에 올립니다. GitHub 저장소의 **Settings → Pages**에서 **Deploy from a branch**를 선택한 다음, 올린 브랜치(보통 `main`)와 **/(root)**를 선택하고 저장합니다.

별도 설치나 빌드가 필요 없습니다. 파일 경로는 상대 경로이므로 저장소 이름이 붙는 주소에서도 사용할 수 있습니다.

GitHub Pages의 웹페이지와 공개 저장소에 올린 파일은 누구나 볼 수 있습니다. 실제 회원정보가 담긴 파일, 화면 캡처, 내보낸 자료는 올리지 마세요. 이 앱에는 로그인 기능이 없으며, 같은 브라우저를 사용하는 사람은 저장된 기록을 볼 수 있습니다.
